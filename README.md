# واجهة نظام العيادة — المرحلة الثانية

## ما تم بناؤه في هذه المرحلة

```
src/
├── styles.css                  الهوية البصرية كاملة (ألوان، خطوط، مكونات)
├── main.jsx                    المسارات فقط
├── lib/
│   └── supabase.js             اتصال Supabase الموحد
├── auth/
│   ├── AuthContext.jsx         الجلسة + ملف الموظف + الدور
│   ├── Login.jsx               تسجيل الدخول
│   ├── Register.jsx            التسجيل الذاتي للموظف (نمط Zoho)
│   ├── AuthSide.jsx            الجانب البصري لشاشات الدخول
│   └── guards.jsx              حارس المسارات + شاشة "بانتظار التفعيل"
├── layout/
│   └── Shell.jsx               السايدبار — الروابط تتغير حسب الدور تلقائيًا
├── users/
│   ├── TeamPage.jsx            الحسابات المعلقة + فريق العمل + إيقاف/تنشيط
│   └── ActivateModal.jsx       نافذة التفعيل: الدور، الفريق، الوزن، الحد اليومي، الهدف
└── pages/
    ├── Dashboard.jsx           أرقام الشهر الجاري (MTD) لكل دور
    └── ComingSoon.jsx          عنصر مؤقت لوحدات المراحل القادمة
```

كل جزئية ملف مستقل — تعديل أي شاشة لا يمس غيرها.

## التشغيل

```bash
# 1) انسخ ملف البيئة وضع بيانات مشروعك
cp .env.example .env
#    من Supabase → Settings → API: انسخ URL و anon key

# 2) ثبّت وشغّل
npm install
npm run dev
```

## دورة تفعيل الموظف (كما طلبت — نمط Zoho)

1. الموظف يفتح `/register` ويسجل بجيميله → حسابه `pending`
2. لو حاول الدخول يرى شاشة "حسابك بانتظار التفعيل"
3. أنت تفتح صفحة **الموظفون** → قسم "بانتظار التفعيل"
4. تضغط "تفعيل وتحديد الصلاحيات" → تختار: الدور، الفريق، هل يدخل التوزيع، وزنه، حده اليومي، هدفه الشهري
5. من لحظتها يدخل النظام ويرى فقط ما يسمح به دوره

**ملاحظة:** أول حساب (حسابك أنت) فعّله يدويًا من Supabase:
```sql
update profiles set status = 'active',
  role_id = (select id from roles where code = 'super_admin')
where email = 'بريدك@gmail.com';
```
